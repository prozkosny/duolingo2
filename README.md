# Angličtina krok za krokem

Interaktivní webová aplikace pro výuku angličtiny pro česky mluvící uživatele.

## Funkce
- Volba pokročilosti **A1–C1** (CEFR), kdykoli změnitelná.
- Pět režimů procvičování:
  - 🃏 **Kartičky** — slovíčko, otočení, sebehodnocení
  - ✅ **Výběr překladu** — vyber český význam
  - ⌨️ **Psaní slovíček** — napiš anglické slovo
  - 🧩 **Skládání vět** — poskládej větu ze slov
  - ✏️ **Doplňování** — gramatika ve větě
- Body (XP), denní série a osobní rekordy uložené v prohlížeči.
- Výslovnost po kliknutí na 🔊.
- Světlý i tmavý režim, funguje na mobilu.

## Spuštění
Stačí otevřít `index.html` v prohlížeči — žádná instalace ani server.

Online: https://prozkosny.github.io/duolingo2/ (po zapnutí GitHub Pages).
